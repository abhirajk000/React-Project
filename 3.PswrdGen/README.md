# 🔐 Password Generator

A modern **Password Generator** built with **React** and **Tailwind CSS**.
It allows users to generate secure passwords with customizable length, numbers, and special characters, and copy them instantly.

---

## ✨ Features

* Random password generation
* Configurable password length (6–32)
* Include numbers and special characters
* One-click copy to clipboard
* Clean, responsive UI

---

## 🛠 Tech Stack

* **React**
* **React Hooks** (`useState`, `useEffect`, `useCallback`, `useRef`)
* **Tailwind CSS**

---

## ⚙️ Core Logic

* `useState` manages password options and output
* `useEffect` triggers password generation on load and updates
* `useCallback` optimizes password generation logic
* `useRef` enables direct DOM access for copying text

---

## ▶️ Getting Started

```bash
npm install
npm run dev
```

---

## 🎯 Purpose

This project demonstrates:

* Effective use of React Hooks
* State and side-effect management
* Clean UI implementation with Tailwind CSS

# 🔢 Counter App

A modern **Counter Application** built using **React** and **Tailwind CSS**.
The app demonstrates state management, conditional logic, and responsive UI design using React Hooks.

---

## ✨ Features

* Increment & Decrement counter
* Min and Max limit handling
* Disabled buttons at limits
* Reset counter to default value
* Modern, responsive UI with Tailwind CSS

---

## 🛠 Tech Stack

* **React**
* **React Hooks** (`useState`)
* **Tailwind CSS**

---

## ⚙️ Core Logic

* `useState` manages the counter value
* Conditional checks prevent overflow and underflow
* Buttons are dynamically disabled based on counter state

---

## ▶️ Getting Started

```bash
npm install
npm run dev
```

---

## 🎯 Learning Outcome

This project showcases:

* Basic React state management
* Event handling in React
* Utility-first styling with Tailwind CSS
* Writing clean and maintainable UI logic

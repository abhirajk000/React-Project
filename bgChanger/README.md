# Background Color Changer 🎨

This is a simple React app where you can change the background color by clicking on color buttons.

## Features
- Click a color button to change the background
- Smooth UI with rounded color board
- Simple and clean design
- Built using React + Vite

## Tech Used
- React
- Vite
- Tailwind
